# 淫欲系统 · 都市模拟

一个**第一人称男主视角**的成人向剧情模拟游戏。玩家扮演周茂文（上海松江大学城大一新生），在开学时意外绑定「淫欲系统」——通过与女性的交流、亲密、性交获取淫欲值，兑换道具技能与现实资产。

纯前端 HTML 单页应用，无后端依赖，可部署到 GitHub Pages 后在手机上玩。

---

## 📁 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 游戏本体（配置 + 引擎 + AI 层 + 全部界面） |
| `names.js` | 4000 个随机名字池（男女对半，用于角色生成） |
| `assets.js` | 900 个现实资产（汽车/房产/奢侈品，每日刷新） |

## 🚀 怎么玩

### 本地（电脑）
直接双击 `index.html` 即可（或起本地服务更稳定）：

```
python -m http.server 8421
```
浏览器打开 `http://localhost:8421/index.html`

### 手机（GitHub Pages）
1. 把这三个文件推到你的 GitHub 仓库
2. 仓库 Settings → Pages → 选 main 分支 → Save
3. 等几分钟，访问 `https://你的用户名.github.io/仓库名/index.html`

## 🤖 AI 配置（推荐开启，否则剧情很平淡）

游戏默认已配置 **DeepSeek 官方 API**（已实测支持浏览器跨域，GitHub Pages 上可直接用）。

**1. 申请 key**：到 [platform.deepseek.com](https://platform.deepseek.com) 注册并创建 API Key（`sk-` 开头）

**2. 填入游戏**：打开 `index.html`，找到文件开头的 `CONFIG.ai`（已默认配好，只需确认 key）：

```js
ai: {
  endpoint: "https://api.deepseek.com/v1/chat/completions",
  apiKey:   "sk-...",                 // 你的 key（当前已填）
  model:    "deepseek-v4-flash",      // 实测可用: deepseek-v4-flash / deepseek-v4-pro
  nsfwLevel: 3,                       // 0=纯爱 1=暧昧 2=露骨 3=深度成人（放开）
  maxTokens: 8000,                    // v4 是推理模型，需较大值（推理+正文）
}
```

**3. 换模型**：`model` 可改 `deepseek-v4-pro`（更强但更慢更贵）；两个都是推理模型（有 reasoning 阶段）

**4. 不填 key**：也能玩，用内置文案池兜底（但剧情是通用模板）

> ⚠️ 注意：key 会暴露在网页源码里，自用没问题；不要把这个仓库设为公开后还带 key。

## 💾 存档

- **自动存档**：每次互动/过天后自动保存到当前档
- **3 个存档位**：系统面板 → 💾 存档，可存/读/删/新开
- **跨设备**：存档页 → 导出 `.json` → 手机浏览器 → 导入，继续玩
- **角色档案**：系统面板 → 📄 角色档案，可查看/下载每个角色的完整记忆卡（.md）

## 🎮 游戏机制速览

- **淫欲值**：性冲动（1:10 折算）、高潮 +500、内射 +1200、破处 ×3、男主破处 +8000、后宫 +50%、女配 ×50%、±30% 波动
- **属性**：颜值/身材/智力/魅力/技巧（25~99）+ 长度/粗度/持久（真实单位，1000 淫欲值/档强化）
- **邂逅**：主界面探索遇新人（随机生成），玩家自主定性：路人/女配/女主（女主 5 上限）
- **后宫**：女主高潮+内射后可收编，5 人上限，入宫后好感永满格、不可取消
- **商城**：一次性道具（每日刷 4）/ 技能（19 项）/ 硬件强化 / 现实资产（每日刷 13，0.4~0.8 折扣）
- **XP 系统**：每个女生有专属性癖（60 种池），AI 剧情贴合
- **记忆系统**：每个角色有独立记忆卡（里程碑永久保留），AI 长期游玩不遗忘
- **独立生活**：女生有自己的生活，10% 概率忙，心情低影响成功率

## 🛠️ 自定义

- **角色池**：改 `CONFIG.girl_pool`（性格/身份/经验各 30 种）
- **XP 池**：改 `CONFIG.xp_pool`（60 种）
- **商城**：改 `CONFIG.shop_items` / `shop_skills` / `shop_hardware`
- **资产**：改 `assets.js` 的 `ASSET_POOL`
- **名字池**：改 `names.js` 的 `NAME_POOL`
- **剧情风格**：改 `buildSystemPrompt()` 里的写作铁律
